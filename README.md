# Car Log — учёт расходов на авто и заправок

Android-приложение на **Kotlin + Jetpack Compose (Material 3)** с локальной базой **Room**.
Один автомобиль, все данные хранятся на устройстве.

## Возможности

- **Заправки**: дата, пробег, литры, цена за литр (итог считается автоматически),
  флаг «полный бак», АЗС, заметка. Редактирование и удаление.
- **Расходы**: дата, категория (ТО, ремонт, страховка, шины, мойка, парковка, штрафы, прочее),
  сумма, заметка.
- **Главная**: средний расход, траты за текущий месяц, последняя заправка, счётчики записей.
- **Статистика**:
  - средний расход (л/100км) по методу полных баков;
  - стоимость 1 км пути по топливу;
  - учтённый пробег и общие траты;
  - столбчатая диаграмма трат по месяцам (топливо + прочее);
  - график динамики цены за литр.
- Светлая/тёмная тема (системная), edge-to-edge.

## Как открыть и запустить

1. Установите **Android Studio** Hedgehog (2023.1.1) или новее — встроенный JDK 17 подходит.
2. `File → Open` и выберите папку `CarLog`.
3. При первом открытии Android Studio предложит синхронизировать Gradle —
   подтвердите (*Sync Now*). Зависимости скачаются автоматически.
   Если Studio спросит про Gradle wrapper — выберите использование wrapper/local distribution,
   она сама подтянет Gradle 8.7.
4. Подключите устройство (Android 8.0+) или создайте эмулятор и нажмите **Run**.

## Как считается средний расход

Метод полных баков: берутся пары соседних заправок «до полного»,
литры, залитые между ними (включая вторую), делятся на пройденное
расстояние по одометру. Поэтому для корректного расчёта важно отмечать
полные заправки флагом «Полный бак» и вводить точный пробег.

## Настройка под себя

- Валюта: константа `CURRENCY` в `ui/Format.kt`.
- Категории расходов: список в `data/Entities.kt` (`ExpenseCategories`).
